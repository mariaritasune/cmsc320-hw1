
Q1: Why might we consider using Git?

Answer: It's a safe way to code with multiple people. It saves a version everytime you push code, in a way
you can go back to it if something goes wrong. It has branches that let you code without messing up the working
code version.

Q2: What field could data science be applied to? Give an Example.

Answer: I believe it can be applied to every field as all have data. An example would be in agriculture,
like tracking cattle/crops to detect problems early on.
